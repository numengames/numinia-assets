# Resource files

No resources are included in the foundation PR. The first import is a
separate, verified-CC0-only cut. Existing resources remain at their sources.

Place admitted files below this directory, grouped by their media type as
needed (for example audio, images, models or avatars). Do not create empty
category placeholders in advance. Keep original identifiers and use the
canonical record in numinia-archive to describe identity and relationships.

This README is documentation under CC-BY-4.0. Its licence does **not** apply
to any other file in this directory. Each resource needs an explicit licence
notice and reviewed provenance; see ../CONTRIBUTING.md.
